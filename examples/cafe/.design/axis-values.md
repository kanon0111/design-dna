# 軸の値（参照から読み取れたもの）

`axes.md` の全7軸について、`picks.json` の参照から**実際に読み取れた値**を記録する。
固定される軸は、ここに書いた値を**積極的に再現する**（ルール5）。
「読み取れず」の軸は**固定できない**ので、案ごとに違う値を選ぶ（ルール7）。

参照は **l162 Ceremony Coffee Roasters 1枚のみ**（Lapa）。
素材は `cache/thumbs/l162.img`（756×1000）を `_slices/l162-1.png` / `-2.png` に分割して確認。
Lapa のサムネは**ページ全体ではなく上部の切り抜き**で、今回は
ヒーロー／商品段／セージの帯の3セクションまでが写っている。
それより下は写っていないので、ページ全体を根拠にする軸は断定できない。

ref が1枚なので、各軸の出どころは自動的に l162 に一意（ルール6は自明に満たす）。
`hint` は空なので、軸ごとの出どころ指定は無い。

| 軸 | 値 | 出どころ | 根拠 |
|---|---|---|---|
| 構図 | **読み取れず** | — | 可視範囲の中で揃っていない。ヒーローと商品段は左の柱に揃うが、ナビは中央ロゴ、セージの帯はラベルも見出しも中央。ページの上部1/6程度しか写っておらず、どちらが支配的か決められない |
| 主役 | 色面 | l162 | 3セクションとも一色の面が画面を仕切っている。写真が無いセクション（セージの帯）はあるが、面が無いセクションは無い。写真は面の中に置かれる小さな被写体で、面のほうが先にある |
| 地の明度 | ライト基調 | l162 | 最暗部でもセージ `#cfddbb`。地は `#fdfbf9`（生成り）と `#ecf0ef`（ミスト）。暗い面が1枚も無い |
| 密度 | 疎（**可視範囲のみ**） | l162 | ヒーローは面の8割が空。商品段も右半分が文字3行だけ。ただしページ全体の詰まり方は写っていないので、断定はしていない |
| コントラスト | 低（トーナル） | l162 | 淡い面どうしの差でしか区切らない。彩度が高いのは被写体のオレンジ1点だけで、面と面の明度差は狭い |
| 階層の跳ね | 中 | l162 | `House Espresso Elevated` と本文が3倍程度。ラベル（`DESTROYER` / `SINGLE ORIGIN`）は小さいが、極端には落としていない |
| 装飾量 | 無 | l162 | 罫線・影・角丸・グラデーションが1箇所も無い。面の境界は色が変わる場所そのもの |

## この読みが今回の生成に与える制約

自由度 50% で `request.json` が固定するのは **構図（28）と主役（22）** だが、

- **構図は「読み取れず」なので固定できない。** 参照の値が無い軸を固定すると、
  再現されるのは参照ではなく適用先の元ページの値になる（ルール5の逆転そのもの）。
  よって構図は**案ごとに違う値を選び**、その旨を `variants.json` の `note` に書く。
- **主役（色面）は読み取れているので固定する。** ただし「触らない」ではなく、
  色面がページを仕切っている状態を能動的に作る。
- 密度は解放される軸なので、可視範囲だけの読みでも実害が無い（案ごとに振る）。

## 骨格枠に Lapa を選んだことの影響

`axes.md` の「素材と軸の対応」どおり、Lapa の切り抜きからは一番重い軸（構図・28）の値が
取れなかった。**自由度 50% と言いながら、実際には 28 ぶんが参照ではなく生成側の裁量で
決まっている。** 構図まで参照に従わせたいなら、フルページのある Godly の ref を
1枚足して `picks.json` に並べる必要がある。
