## l162 — Ceremony Coffee Roasters（役割: 骨格）

見たもの: `cache/thumbs/l162.img`（756x1000）を `_slices/l162-1.png` / `-2.png` に2分割して確認
拾った色: `#fdfbf9` 27%（生成り） / `#ecf0ef` 38%（ミスト＝ミルク） / `#cfddbb` 19%（セージ＝葉） /
`#fbe9d8`（ピーチ＝果実） / `#b4875e` 4.5%（焙煎）

### 軸の読み

| 軸 | 読み取った値 | 根拠 |
|---|---|---|
| 構図 | 左寄せ | 見出し・説明・CTA が左の柱に揃い、被写体が右。下段も左端から始まる |
| 主役 | 色面 | セクションごとに違う一色の面が敷かれ、それが画面を仕切っている |
| 地の明度 | ライト基調 | 最暗部でもセージ `#cfddbb`。暗い面が一枚も無い |
| 密度 | 中 | 面はたっぷりだが、面の中の文字は少ない |
| コントラスト | 低（トーナル） | 淡い面同士の差でしか区切らない。彩度が高いのは被写体のオレンジだけ |
| 階層の跳ね | 中 | 見出しと本文が3倍程度。ラベルは小さいが極端には落としていない |
| 装飾量 | 無 | 罫線も影も無い。境界は色が変わる場所そのもの |

### 借りたい属性

- **色を素材から取る**。セージ＝葉、ピーチ＝果実、ミスト＝ミルク、`#b4875e`＝焙煎。
  ブランドカラーを決めてから塗るのではなく、置くものの色を薄めて面にしている
- セクションごとに面の色を替えることで、罫線なしに切り替わりを作る
- ボタンに相当する `SHOP NOW` が、塗りボタンではなく極小キャプスのまま置かれている
- 書体は2系統。`House Espresso Elevated` / `Freshest of the Fresh` / `Taste by Color` は
  すべてセリフ、`DESTROYER` / `SINGLE ORIGIN` / `NEW ARRIVALS` / `LET COLOR BE YOUR GUIDE` は
  同じサンズを大文字＋字間で落としただけ。3つ目の書体を足していない
- 強調が「大きくする」「離す」の2手だけ。色替え・太字・囲みが1箇所も無い
- 影・角丸・グラデーションが1箇所も無い。画像も色面も矩形のまま

### 借りない部分

- 白背景で切り抜いた商品の物撮り（りんご、タルト）。EC の見せ方であってカフェの1ページには要らない
- 価格とカート数を伴うカード列。買い物導線の骨格ごと持ってくると滑る
- 真上から撮ったフラットレイ
- 検索・アカウント・カート数を並べた EC のグローバルナビ（中央ロゴ＋左右振り分け）

## ref が1枚になったことの扱い

run-02 / run-03 は l134 Les Ensembliers と2枚で組み、**両方に共通して現れた方針だけ**を
DNA に入れていた。今回 `picks.json` から l134 が外れたため、その照合ができない。

代わりに、**l162 の中の複数箇所で繰り返されている**方針だけを不変条件にした。
たとえば「塗りボタンを使わない」はヒーローの `SHOP NOW` と下段の `SHOP NOW` の2箇所、
「境界は色の切り替わり」はヒーロー／商品段／セージの帯の3箇所で成立している。
1箇所しか出てこない処理（例: 商品カードの中で価格だけ級数を落とす扱い）は DNA に入れていない。

l134 由来だった不変条件のうち、**l162 単体では支持されないもの**は落とした。

- 「中間にあたるサンズの本文サイズを作らない」→ l162 は本文がサンズ。落として、
  級数差は軸「階層の跳ね」に預けた

## 和文に移すときの注意

欧文は字間を開けても読める。和文は開けると読めなくなるので、
字間の芸は**ラテン文字のラベルだけ**に限定し、和文の見出し・本文には持ち込まない。
折り返し幅も `ch`（欧文の 0 の幅）ではなく `em` で取る。
