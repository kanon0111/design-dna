- 強調が級数と余白だけで作られている。色も太字も囲みも使っていない

## l162 — Ceremony Coffee Roasters（役割: 色）

見たもの: `cache/thumbs/l162.img`
拾った色: `#fdfbf9` 28% / `#ecf0ef` 38%（ミスト） / `#cfddbb` 19%（セージ） / `#b4875e` 4.5%（焙煎）

### 軸の読み

| 軸 | 読み取った値 | 根拠 |
|---|---|---|
| 構図 | 左寄せ（ヒーロー）＋グリッド（商品段） | 見出しは左、被写体が右。下段は等幅の2枚並び |
| 主役 | 色面と画像 | セクションごとに違う一色の面が敷かれ、それが画面を仕切っている |
| 地の明度 | ライト基調 | 最暗部でもセージ `#cfddbb`。暗い面が一枚も無い |
| 密度 | 中 | 面はたっぷりだが、面の中の文字は少ない |
| コントラスト | 低（トーナル） | 淡い面同士の差でしか区切らない。彩度が高いのは被写体のオレンジだけ |
| 階層の跳ね | 中 | 見出しと本文が 3 倍程度。ラベルは小さいが l134 ほど落としていない |
| 装飾量 | 無 | 罫線も影も無い。境界は色が変わる場所そのもの |

### 借りたい属性

- **色を素材から取る**。セージ＝葉、ピーチ＝果実、ミスト＝ミルク、`#b4875e`＝焙煎。
  ブランドカラーを決めてから塗るのではなく、置くものの色を薄めて面にしている
- セクションごとに面の色を替えることで、罫線なしに切り替わりを作る
- ボタンに相当する `SHOP NOW` が、塗りボタンではなく極小キャプスのまま置かれている

### 借りない部分

- 白背景で切り抜いた商品の物撮り（りんご、タルト）。EC の見せ方であってカフェの1ページには要らない
- 価格とカート数を伴うカード列。買い物導線の骨格ごと持ってくると滑る
- 真上から撮ったフラットレイ

## 両方に共通していたこと（＝ DNA の候補）

- 書体は2階級だけ。セリフの見出し／字間を開けた極小キャプスのラベル。中間サイズのサンズ本文が無い
- UI 部品（ボタン・リンク）に固有の色を与えていない。色は素材由来の面としてだけ現れる
- 影・角丸・グラデーションが1箇所も無い。面の境界は色の切り替わりそのもの
- 画像も色面も矩形のまま。切り抜き形状で遊ばない
- 強調が「大きくする」「離す」の2手だけで作られている

## 和文に移すときの注意（両 ref 共通のリスク）

欧文は字間を開けても読める。和文は開けると読めなくなるので、
字間の芸は**ラテン文字のラベルだけ**に限定し、和文の見出し・本文には持ち込まない。
折り返し幅も `ch`（欧文の 0 の幅）ではなく `em` で取る。
