## 不変条件

1. **書体は1系統だけ。**
   見出しも本文もラベルも CTA も同じファミリーで組む。2つ目の書体を足さない。セリフを混ぜない。
   太さの段は使ってよいが、**別の顔**は持ち込まない。

2. **見出しを太らせない。太字は最小級のラベルにしか使わない。**
   ページで一番大きい文字が一番太い、という組み方をしない。
   （ヒーロー見出し・節見出し・数値・暗帯の大見出し、全帯で同じレギュラー相当だった）

3. **色はぼかした面にしか置かない。文字・罫線・ボタン・地は無彩色。**
   語を目立たせるために色を変えない、囲まない、下線を引かない。
   アクセント色という考え方を持たない。色を運ぶのは面だけ。

4. **画像・色面は必ず輪郭がぼけていて、地に溶けて終わる。**
   縁の立った矩形の画像を置かない。中身を読ませない。面は情報ではなく空気として置く。

5. **区切りに塗りの箱・カード・パネル・影を使わない。**
   地は左右端まで届く水平の帯で切り替える。帯の中に別の地色の箱を作らない。
   地は帯であって、部品ではない。

6. **構造物（区切り・地紋・背景の大きな字）は、地との差を10/255前後に留める。**
   骨格は「見ようとすれば見える」以上に出さない。読ませるのは文字だけ。

7. **影・ベベル・立体化・グラデーションのボタンを使わない。** 奥行きは地の明度差とぼかしだけで作る。

8. **文字の濃度は必ず3段に分ける。**
   地に対して最大差を持つのは見出しだけ。本文はそこから一段、ラベル・通し番号はさらに一段落とす。
   見出し・本文・ラベルが同じ濃さで並ぶことがない。暗い帯の上でも同じ3段を作る。

9. **本文は狭い段に折り返して2〜5行の塊にする。1行で横に伸ばさない。**
   和文の折り返し幅は `em` で取る（`ch` は欧文基準で足りない）。

10. **CTA は単色塗りの小さな矩形。枠も影もグラデーションも足さない。見出しより小さく保つ。**

11. **和文の見出し・本文・ラベルに字間を開けない。** 開けてよいのはラテン文字だけ。

## 借りない部分

ref 固有の芸は移植すると滑る。以下は DNA に含めない。

- グローバルナビ（What we do / Who we serve / About us / View docs / Log in / Contact）。`content.md` にナビは無い
- 顧客ロゴの横並び帯（SoFi / coinbase / Revolut / tether …）。ロゴ素材も文言も無い
- 巨大な指標の並置（65+ / 99.99% / 2–5 / 3–5x）。`content.md` に数値の実績は無い
- Trusted by の証言カードと左右送りの矢印。証言が無い
- 6カラムのサイトマップ・フッター。リンクが無い
- 製品UIのスクリーンショットとデバイスモックアップ（スマートフォン／ラップトップ）
- CTA を2つ並べる処理（Book a demo ＋ Get API key）。`content.md` の CTA は「予約する」1つ
- `Documentation` / `Sandbox` のような英語の極小ラベルを、和文ページのために英語で捏造すること
- 欧文の語間・字詰めでだけ成立している組みを、和文にそのまま当てること

## ここに書かなかったもの（＝軸に置いたもの）

`axes.md` ルール4 のため、以下は DNA ではなく軸として扱う。
g07 では全部読めるが（値は `axis-values.md`）、DNA に書くと自由度で永久に動かなくなる。

- 中心に軸を通すか外すか（→ 軸「構図」）
- 文字・画像・色面・余白のどれを主役に据えるか（→ 軸「主役」）
- 地がどちらに寄るか、どこで反転するか（→ 軸「地の明度」）
- 面の中をどれだけ空けるか（→ 軸「密度」）
- 地と見出しの明暗差をどこまで開くか（→ 軸「コントラスト」）
- 見出しとラベルの級数差をどこまで開くか（→ 軸「階層の跳ね」）
- 罫線を引くか、通し番号を添えるか、巨大なゴースト字を敷くか、地紋を足すか（→ 軸「装飾量」）
  ※ g07 は縦横の罫線＋01/02/03＋末尾の巨大ロゴタイプを持つが、これは装飾量の**値**なので DNA に書かない
