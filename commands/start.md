# design-dna : start

AI に「おしゃれに」と頼むと**良いデザインの平均**が返る。平均には個性がないので
どれも似た顔になる。これはそれを避けるための仕組み。

**ビルトインの `/design` とは別物**。あちらは Claude Design のキャンバス。
こちらは参照の選別と、そこからの案の生成。混同したら、この文章が読めているほうが design-dna。

やり直したいときは `/design-dna:reset`。

## いまの状況を掴む

まず、このプロジェクトが**どういうものか**を自分で読み取る。利用者に白紙の欄を
埋めさせない。

- `package.json` / `README` / `pyproject.toml` — 何のプロダクトか
- ルーティング・ページ・コンポーネント — どんな画面があるか
- 実際の文言 — 誰に向けて、どんな声で書かれているか
- **既存のデザインシステムの有無** — `tokens.css` / `theme.*` / `tailwind.config.*` /
  `design-system/` / `ui/` / Storybook / `assets/` のブランドフォント

読み取った内容を **1〜2行の brief に下書きして見せる**。推測は必ず表示して、
直せる状態にすること。黙って決めない。

### ここで分岐する

| 状況 | やること |
|---|---|
| **既存のデザインシステムがある** | その語彙を**拡張する**。トークン・コンポーネント・密度に合わせる。自分の DNA を上書きしない。何に合わせたかを1行で言う |
| **ゼロから** | 以下の流れに進む |

既存アプリに別の DNA を被せるのは改善ではなく破壊。ここは最初に宣言する。

## 流れ

```
参照227件 → 系統6つに分類（実測値ベース）
   ↓  役割ごとに1枚ずつ選ぶ（骨格 / 色 / 文字）
DNA を抽出（両方の ref に共通する方針だけ）
   ↓  自由度 N% で解放する軸を決める
案を複数生成（案ごとに解放する軸をずらす）
```

## 起動

```
python "${CLAUDE_PLUGIN_ROOT}/tools/serve.py" 8000
```

プロジェクトのルートで実行すること。**実行したディレクトリが適用先**になり、
結果は `<project>/.design/` に書かれる（`DESIGN_DNA_PROJECT` で上書き可）。

http://localhost:8000/picker.html を開いて利用者に渡す。

- **自分で選ぶ** — 系統6つ → 詳細 → 骨格枠に1枚（色・文字は任意）
- **おまかせで選ぶ** — brief を書いて押すと、`claude -p` が headless で走り、
  227件から理由つきで提案する。**提案どまり**で、採用するかは利用者が決める

自由度と案の数を決めて「決定」を押すと生成ジョブが走り、
終わると `/compare.html` に飛ぶ。

## 守るべきこと

`${CLAUDE_PLUGIN_ROOT}/axes.md` を読むこと。特に:

- **ルール4** — DNA に軸の**値**を書かない。書くとその軸は自由度で永久に動かなくなる。
  DNA に入れてよいのは「アクセント色を持たない」のような**方針**だけ。
  （「左寄せ非対称」「地は黒と生成り」を DNA に書いて、
  自由度をいくら上げても雰囲気が変わらない事故を実際に起こしている。）
- **ルール2** — 同じ自由度で複数案を出すときは、**案ごとに解放する軸をずらす**。
  同じ予算でも壊す場所が違えば、案同士も似ない。

平均化が起きるのは「**同じ属性に複数の参照が入る**」時だけ。だから枠を役割で分ける。
1枚だけだとその1サイトの模倣になり、多く選ぶと平均になる。

## 書き込んでよい場所

| | |
|---|---|
| 書いてよい | `<project>/.design/` の中だけ |
| 読むだけ | `${CLAUDE_PLUGIN_ROOT}/`（参照プール・軸・picker） |

参照プールは全プロジェクト共通なので、絶対に書き換えない。

## 初回だけ必要なこと

参照プールに画像キャッシュが無いと、AI が実物を見て選べない。

```
python "${CLAUDE_PLUGIN_ROOT}/tools/fetch_thumbs.py"
```

候補一覧・測定値・クラスタはプラグインに同梱されているので、収集し直す必要はない。
参照を増やしたいときだけ `fetch_lapa.py` → `fetch_thumbs.py` →
`analyze_thumbs.py` → `cluster_thumbs.py` → `build_picker.py` の順に回す。

## やり直す

```
python "${CLAUDE_PLUGIN_ROOT}/tools/reset.py"
```

`.design/` の1回分だけを初期化する。生成済みの案は `.design/runs/run-NN/` に退避され、
参照プールには触らない。
